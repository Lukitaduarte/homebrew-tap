# Homebrew tap

```sh
brew install --cask lukitaduarte/tap/orc-harness
```

Then open **Orc Harness**. It sets up its daemon and connects by itself.

| Cask | |
| --- | --- |
| [`orc-harness`](Casks/orc-harness.rb) | [Orc Harness](https://github.com/Lukitaduarte/orc-harness): many Claude Code sessions in parallel, from desktop and phone |

The cask is updated by the [release workflow](https://github.com/Lukitaduarte/orc-harness/blob/main/.github/workflows/release.yml).
